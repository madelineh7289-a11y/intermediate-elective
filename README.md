# Week 7, Spring 2026: Intermediate Elective Option 2



## General information

This repository contains data and code to explore patterns in aquatic invertebrate samples by site and person entering the data at North Campus Open Space. More advanted visualization techniques are used to tell a more engaging and interesting story.

To work with the code in this repository, you will need the following packages:

```
library(tidyverse)
library(here)
library(janitor)
library(NatParksPalettes)
library(readxl)
```
